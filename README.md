## 🚀 Quick Start Guide

### 📦 Setup

run the command to be able to exec the script and setup all the enviroment
```bash
chmod +x start_project.sh
```

### 🚀 Run the Script

To automatically set up the environment and start the project, simply run the script:

```bash
./start_project.sh
```

What the Script Does:

- **Checks** if the virtual environment (env/) exists and creates it if not.
- **Activates** the virtual environment
- **Installs** all dependencies from `requirements.txt`.
- **Starts** the project by running `main.py`.
